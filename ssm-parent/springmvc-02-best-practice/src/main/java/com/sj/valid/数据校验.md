
# 数据校验

1. 导入校验依赖
2. 编写校验注解
3. 告诉springmvc 进行校验, 通过@Valid 注解 
    效果1: 如果校验不通过,目标方法不执行
4. 在 @Valid 参数后面,紧跟着一个 BindingResult
    但是这种写法比较麻烦


可以使用全局异常处理,当校验出错,会抛出MethodArgumentNotValidException异常,然后被@ExceptionHandler注解的方法捕获
```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public  R  method (MethodArgumentNotValidException ex){
	BindingResult bindingResult = ex.getBindingResult();
	List<FieldError> fieldErrors = bindingResult.getFieldErrors();
	
	Map<String, String> map = new HashMap<>();
	for (FieldError fieldError : fieldErrors) {
		String field = fieldError.getField();
		String defaultMessage = fieldError.getDefaultMessage();
		map.put(field, defaultMessage);
	}
	
	return R.error(400, "参数校验失败", map);
}
```
