
# spring中 bean的声明周期

	  1. 构造器
	    自动注入 @autowired
	    postProcessBeforeInitialization
	    @PostConstruct
	    InitializingBean 接口的 afterPropertiesSet 方法
	  2. initUser
	    postProcessAfterInitialization
	    @PreDestroy
	    DisposableBean 接口的 destroy 方法
	  3. destroyUser


解释:
spring 在 bean的创建过程中, 埋下了很多的回调钩子
1. 首先要 先执行构造器
2. 执行 @Autowired的自动注入
3. 执行 BeanPostProcessor 的  postProcessBeforeInitialization方法
4. 执行 标注了 @PostConstruct 的方法
5. 执行 InitializingBean接口的 afterPropertiesSet 方法
6. 执行 @Bean 注解指定的 初始化方法,此处是 initUser方法
7. 执行 BeanPostProcessor的 postProcessAfterInitialization 方法
8. 执行 标注了 @PreDestroy  的方法
9. 执行 DisposableBean接口的 destroy 方法
10. 执行  @Bean 注解指定的 destroyUser 方法

其中 BeanPostProcessor 的功能强大, 他拦截所有的 bean
他就相当于拦截器
而且可以对bean做修改,进行后续处理
