# statefulset

StatefulSet 是用来管理有状态应用的工作负载 API 对象。

StatefulSet 用来管理某 Pod 集合的部署和扩缩， 并为这些 Pod 提供持久存储和持久标识符。
    这句话说明 statefulset 和 deployment 具有相同的功能, 而且更加强大

和 Deployment 类似， StatefulSet 管理基于相同容器规约的一组 Pod。但和 Deployment 不同的是，
StatefulSet 为它们的每个 Pod 维护了一个有粘性的 ID。这些 Pod 是基于相同的规约来创建的，
但是不能相互替换：无论怎么调度，每个 Pod 都有一个永久不变的 ID。

解释: 如果通过 deployment 启动3个节点 nginx 此时 如果 他们的名字其实是随机的, 假设在一个nginx宕机, deployment 重新部署一个,
此时新的 nginx和 宕机的nginx的名字是不同
但是如果是 statefulset , 此时此时新的 nginx,和宕机的nginx 名字是一样
这样做, 可以 保证他们在 数据挂载的时候,保证数据不丢失

statefulset 适合部署的应用
● 数据库（MySQL、PostgreSQL、Cassandra）
● 分布式协调服务（ZooKeeper、etcd）
● 消息队列（Kafka、RabbitMQ）
● 需要固定网络标识和稳定存储的应用

statefulset 部署的应用, 数据放在哪里?
1. 云厂商块存储 (Cloud Disk)
    生产环境首选，尤其是对数据可靠性要求高的核心应用
    缺点:成本高
    优点: 高可用、高性能 数据可靠性高，由云平台保证

2. 本地持久卷 (Local PV)
    直接使用工作节点的本地磁盘
    优点: 性能极高
    缺点: 需要 人工干预数据的 不丢失,需要自己备份
    适合场景: 对性能要求极高，且可以接受节点级故障风险的场景（如部分缓存系统）

3. 网络存储 (NAS/SAN)
    通过CSI插件挂载外部存储（如NFS, Ceph）
    优点: 支持共享读写 (ReadWriteMany),便于Pod间共享数据
    缺点: 性能是瓶颈, 网络延迟和带宽可能成为制约因素
    适合场景: 需要在多个Pod之间共享数据的场景（如内容管理系统）

说明: 视频中这里使用 nfs 的方式 具体做法描述如下
1. 首先 克隆了一台新的服务器
2. 在 这台服务器上安装了 nfs, 并且指定了一个 /nfs/data 目录
3. 接着在k8s集群中 安装了一个 nfs-utils的工具
4. 在k8s集群上也创建了一个 /nfs/data 目录
5. 最终 用 k8s集群的/nfs/data 目录 和  nfs服务器上的 /nfs/data 目录 进行了挂载







pvc 和 pv 是什么,他们之间的关系?

PVC (PersistentVolumeClaim) 相当于使用者提交的“硬盘采购申请单”（对存储资源的请求）。 claim 的意思是 声称”、“主张”或“索要
PV (PersistentVolume) 相当于仓库里的一块“物理硬盘”（集群级别的存储资源）。

它们分别是什么？
PV（持久卷）：它是集群中的一块存储资源，由集群管理员提前准备好。
它"不隶属于任何一个Pod或命名空间"，是全局资源。它代表了真实的物理存储，
比如一块NFS网络硬盘、一个Ceph块设备，或是一块云厂商的云硬盘（如AWS EBS）。

PVC（持久卷声明）：它是Pod发起的“需求清单”，由开发者或用户创建，必须位于某个具体的命名空间下。
申请单上会写明需求，比如“我需要 10GB 存储空间”且“必须支持一次只能被一个节点读写 (ReadWriteOnce)”。

它们之间的关系（绑定与供应）
PVC和PV通过“绑定（Binding）”建立关系。Kubernetes会根据PVC的申请条件，在集群中寻找一个符合要求的PV，然后将两者绑定在一起。

这个“绑定”过程有两种实现模式：
静态供应（提前备货）：管理员先手动创建好一批PV（比如预先买了5块云盘），
等着用户来申请。当用户提交PVC时，Kubernetes会去“仓库”里匹配一块空闲且规格（容量、访问模式）符合的PV。匹配成功则绑定，用户就能用了。

动态供应（按需生产）：这是云环境下最主流的方式。管理员只需提前定义一个“模板（StorageClass）”
（比如指定用阿里云SSD云盘）。当用户提交PVC时，Kubernetes发现没有现成PV可用，就会自动调用云厂商的API，当场创建一块新的云盘（PV），
并立即绑定给这个PVC。

简单理解:
pv 就是 持久卷, 就是对一块存储空间
pvc  是 声明, 声明我要 多大的存储空间
也就是：Pod 挂载（使用）PVC，而 PVC 绑定（匹配）PV。
