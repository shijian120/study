# 版本回退
# 版本回退类似 git ,当我们部署了之后,可以进行 版本控制

# rollout 是 部署新版本的意思, 而 rollback 才是 回滚的意思

仅当 Deployment Pod 模板（即 .spec.template）发生改变时，例如模板的"标签"或"容器"镜像被更新，
才会触发 Deployment 上线。其他更新（如对 Deployment 执行扩缩容的操作）不会触发上线动作。, 也就不会有新版本

#  查看部署状态
kubectl rollout status [deployment nginx-deployment | deployment/nginx]

# 查看部署的历史
kubectl rollout history deployment nginx-deployment
# 这种写法和上面的写法是一样的效果
kubectl rollout history deployment/nginx-deployment


# 回退到上一个版本
kubectl rollout undo deployment nginx-deployment

# 重新部署
kubectl rollout restart deployment nginx-deployment

# 暂停
kubectl rollout pause deployment nginx-deployment


# 恢复
kubectl rollout resume deployment nginx-deployment
